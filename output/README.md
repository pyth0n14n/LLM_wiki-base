# Output

This directory is for temporary generated artifacts: drafts, exports, reports,
tables, or other files that are useful during a session but are not yet part of
the maintained wiki.

Durable knowledge should not stay here. If an output is worth keeping, move the
substance into:

- `wiki/syntheses/` for settled analysis, comparisons, or conclusions
- `wiki/questions/` for unresolved investigations or research plans

Do not use this directory as a second wiki.
